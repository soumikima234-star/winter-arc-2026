WINTER ARC 2026
================
A responsive, local-first Progressive Web App based on the supplied specification.

RUN:
1. Put these files on any static web host, or serve the folder with a local HTTP server.
2. Open index.html in a browser. For PWA installation/service worker, use HTTPS or localhost.
3. Data is stored in browser localStorage.
4. Use Settings > Backup JSON before changing browser/device.

FEATURES:
Dashboard, monthly habit grid, daily targets, backlog, fitness, timers, calendar, statistics,
discipline coins, personal rewards, settings, JSON backup, CSV export, responsive mobile/desktop UI.

NOTE:
Browser-based step sensors and background alarms vary by OS/browser. The app provides manual steps
and browser notification permission where supported. A production native wrapper can add deeper
health-platform integration and OS-level scheduling.
